# Ribeiro's Tech — Página de Vendas

Página de vendas oficial da Ribeiro's Tech para apresentação e contratação de serviços de criação de sites.

##  Sobre o projeto

Landing page desenvolvida para apresentar os serviços da Ribeiro's Tech, seus planos de criação de sites, projetos desenvolvidos e processo de contratação.

O objetivo é oferecer uma experiência moderna, clara e responsiva para clientes interessados em criar sua presença digital.

##  Serviços

### Landing Page
**R$ 220,00**

Página única, moderna e focada em apresentar um produto, serviço, profissional ou campanha.

### Site Profissional
**R$ 350,00**

Site institucional responsivo para apresentar empresas, serviços, informações e canais de contato.

### Site Premium
**R$ 560,00**

Site com experiência visual mais sofisticada, recursos avançados, animações e maior nível de personalização.

> Os valores podem ser atualizados conforme a necessidade dos projetos.

A contratação dos serviços será realizada através de checkout online.

Caso o cliente deseje um domínio próprio, a disponibilidade e o valor serão verificados antes da contratação.
